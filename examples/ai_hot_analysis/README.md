# Daily AI Hotspot Analysis

This Task uses the `daily-ai-hotspots` Skill to plan source coverage, execute one Graph Intent at a time, supervise gaps, and prove a daily digest Goal.

```bash
npm run build
node dist/cli.js run examples/ai_hot_analysis/task.json
```

Authenticate OpenCode before running. Project state is written under `PEAK_HOME/projects/<uuid>/`.
